ONTOLOGY STUDIO

개념을 정의하고.
사실을 추론하다.

RDF / OWL RL / SHACL / SPARQL · 브라우저에서 작성하고 서버에서 실제 실행

온톨로지: 클래스·속성·개체와 의미 규칙을 명시한 모델. 지식 그래프는 이 모델로 표현한 구체적인 사실의 연결입니다.

추론과 검증: OWL의 domain/range는 타입을 추론합니다. 필수 관계와 데이터 품질은 SHACL이 검사합니다. 모든 GraphRAG가 OWL 온톨로지를 요구하지는 않습니다.
