    03 / LIVE LABORATORY
    Don't just learn it.
    Run it.
    문서 → 인덱스 → 검색 → 근거 → 답변. 실제 파이프라인을 확인하세요.
     INTERACTIVE EXPERIMENT
    
        
    함께 해보기 / 약 6분
    연결을 이용하면 어떤 원문을 더 찾을까요?
    온톨로지에서는 규칙으로 추가된 사실을 봤습니다. 여기서는 질문에 답하려고 어떤 문서를 골랐는지 확인합니다.
    1. 예제와 질문 준비
      위 준비 버튼을 누르면 기본 문서, Offline Demo, HippoRAG와 여러 문서를 연결하는 질문이 설정됩니다. 직접 편집한 문서는 기본 예제로 바뀝니다. API 호출 없이 준비만 합니다.
    2. 검색·답변 실행
      왼쪽의 검색·답변 실행을 누르세요. 문서를 바꿨다면 인덱스도 다시 만듭니다. 처음에는 Offline으로 검색 흐름을 확인합니다. Offline의 답변은 예제 근거를 정리한 미리보기입니다.
    3. 답보다 먼저 근거 확인
      검색 근거에서 고른 원문을 읽고, 아래 QUERY EXECUTION의 입력 쿼리·후보 점수·실행 검색 작업을 펼쳐 보세요. 회사, 시스템, 모델, 데이터가 이어질 근거가 모였는지 확인합니다.
    4. 같은 질문으로 비교
      방법별 결과 비교에서 Hybrid / Lexical baseline과 HippoRAG를 고르고 두 방법 비교를 누르세요. 선택된 원문이 어떻게 달라지는지 봅니다. 그래프가 항상 더 낫다고 가정하지 않습니다.
    예제 이름 읽는 법
    Atlas = 물류 시스템, Beacon = 배송 지연 예측 모델, TrafficStream = 교통 데이터, Orion = 전처리 파이프라인, 오로라 물류 = 고객사. D1·D2 등은 원문 문서 번호입니다. PPT의 날씨 예제와 같은 연결 문제를 교통 데이터로 살펴봅니다.
    관찰 질문: “질문에 직접 나오지 않은 중간 대상의 원문도 찾았나요?” 준비 과정은 INDEX BUILD, 질문별 검색 과정은 QUERY EXECUTION에서 봅니다. Live를 선택하면 모델 호출과 비용이 발생합니다.
    발표할 때 이렇게 연결해 보세요
    “앞에서는 정의한 규칙으로 어떤 사실이 추가되는지 봤습니다. 이번에는 연결이 여러 문서에 흩어져 있을 때 답변에 쓸 근거를 찾아보겠습니다. 예제 이름이 낯설면 위의 역할 설명을 보시면 됩니다. HippoRAG로 한번 실행하고, 최종 답보다 어떤 원문을 골랐는지부터 확인해 주세요. 마지막에는 같은 질문으로 기본 검색과 비교해 보겠습니다.”
